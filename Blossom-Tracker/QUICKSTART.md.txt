# ⚡ Quick Start (5 Minutes)

Get your app live in 5 minutes!

## 📥 What to Upload

Copy these files to your GitHub repository:

```
✅ index.html           (Main app file)
✅ manifest.json        (PWA config)
✅ README.md            (Documentation)
✅ LICENSE              (MIT License)
✅ .gitignore           (Git ignore rules)
✅ ICON-GUIDE.md        (How to make icons)
✅ DEPLOYMENT-GUIDE.md  (Detailed setup)
⏸️ icon-192.png         (Optional - add later)
⏸️ icon-512.png         (Optional - add later)
```

## 🚀 3-Step Deploy

### 1️⃣ Create Repository
- Go to https://github.com/new
- Name: `womens-cycle-tracker`
- Click "Create repository"

### 2️⃣ Upload Files
- Click "Upload files"
- Drag all files (except icons if not ready)
- Click "Commit changes"

### 3️⃣ Enable GitHub Pages
- Go to Settings → Pages
- Source: Branch "main" → Folder "/ (root)"
- Click "Save"

**Done!** Your app is at:
`https://yourusername.github.io/womens-cycle-tracker/`

## 📱 Install on Phone

### iPhone
1. Open in Safari
2. Tap Share → "Add to Home Screen"

### Android
1. Open in Chrome
2. Menu → "Add to Home Screen"

## 🎨 Add Icons Later

Icons make it look professional, but they're optional.

**Without icons**: App works perfectly, just no custom icon when installed  
**With icons**: Professional app icon on home screen

See `ICON-GUIDE.md` for easy methods to create them.
